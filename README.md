# 대상물 크로스 체크

부서마다 따로 내려온 엑셀 대상물 목록 **2개~8개**를 맞대어, 대상물마다 **어느 목록에 들어 있는지**, **한 목록에만 있는 대상**, **가까운 주소에 모인 대상**을 찾아 주는 웹 도구입니다. 점검·교육 대상을 팀별로 배분하기 전에 목록을 정리하는 용도로 만들었습니다.

- 설치 없이 브라우저(크롬, 엣지)에서 바로 실행됩니다.
- 올린 파일은 **브라우저 안에서만 처리**되며 서버나 외부로 전송되지 않습니다.
- 인터넷이 없는 PC에서도 동작합니다. 엑셀 처리 라이브러리를 파일 안에 넣어 두었습니다.

---

## 사용 방법

### 1. 파일 올리기
**파일 추가** 칸에 엑셀 파일을 끌어다 놓거나, 칸을 눌러 파일을 고릅니다. 여러 파일을 한 번에 골라도 됩니다.

- 파일은 2개부터 **최대 8개**까지 올릴 수 있습니다. 파일마다 A, B, C… 글자와 색이 붙어 결과 화면에서 구분됩니다.
- 파일 카드의 **바꾸기**로 그 파일만 다른 파일로 바꾸고, **빼기**로 비교에서 뺍니다.
- 지원 형식: `.xlsx`, `.xls`, `.xlsm`, `.csv` (CSV는 UTF-8과 EUC-KR 모두 읽음)
- **부서/구분 이름**: "예방과", "대응단"처럼 적어 두면 결과 화면과 엑셀 시트 이름에 그대로 쓰입니다.
- **시트**: 시트가 여러 개인 파일은 카드에 시트 버튼이 나옵니다. **고른 시트를 모두 합쳐 한 목록**으로 비교합니다(예: 중점관리·특급·1급·2급·3급 시트를 합쳐 한 부서의 전체 대상).
  - 처음에는 표가 있는 시트가 모두 골라지고, 이름에 "참고"가 들어간 시트는 빠집니다. 버튼을 눌러 넣고 뺍니다.
  - 시트마다 열 구성이 달라도 열 이름으로 맞춰 합칩니다. `건 물 명`, `학교명` 같은 열은 `대상물명`으로 모읍니다.
  - 결과에는 시트 이름과 행 번호가 함께 나옵니다(예: `1급대상 시트 149행`).
  - **해당 구분**: 같은 대상이 여러 파일·여러 시트에 흩어져 있으면, 그 대상이 무엇에 해당하는지 한 칸에 모아 보여 줍니다.
    예: `훈련: 특급대상, 중점관리대상, 고층건축물 / 조사: 중점관리대상, 특급` (파일이 시트 하나면 파일 이름만)
    대조표 화면, 통합 결과 엑셀(대조표·중복대상·배분용 전체대상·배정 팀), 현장점검용 파일 비고에 들어갑니다.
  - 시트가 여러 개인 파일은 **하나만 올려도** 시트끼리 비교합니다(같은 대상이 어느 시트들에 있는지).
  - 시트마다 다른 부서 목록이라 서로 비교해야 한다면, 같은 파일을 한 번 더 올리고 카드마다 다른 시트를 고르세요.
- **머리글 행**: 자동으로 찾습니다. 위에 문서 제목, 작성일, 단위, 빈 줄이 있어도 건너뛰고 표의 머리글 줄을 고릅니다. 자동으로 고른 행에는 `자동` 표시가 붙습니다.
  - 잘못 잡혔으면 숫자를 직접 고칩니다. 다시 자동으로 돌리려면 `자동으로`를 누릅니다.
- **병합 셀**: 그대로 올려도 됩니다.
  - 세로로 병합된 칸(예: 한 건물에 업소가 여러 개라 `건물명`·`주소`가 병합된 경우)은 병합된 모든 행에 같은 값이 들어간 것으로 읽습니다.
  - 머리글이 병합으로 두 줄이면(예: `소재지` 아래 `도로명 / 지번`) `소재지 도로명`, `소재지 지번`처럼 한 이름으로 합칩니다.
  - 병합 없이 빈칸만 둔 두 줄 머리글은 위 줄만 머리글로 잡고 아래 줄을 데이터로 읽습니다. 이때는 엑셀에서 머리글을 한 줄로 합쳐 두세요.

### 2. 비교 기준 정하기
파일마다 같은 대상인지 판단할 열을 고릅니다. 열 이름이 파일마다 달라도 됩니다(예: `대상물명` ↔ `명칭` ↔ `업체명`).

- "대상물명", "명칭", "업체명", "주소", "소재지" 같은 열은 자동으로 골라 줍니다.
- **비교 항목 추가**를 누르면 여러 열을 함께 비교합니다. 이때는 모든 항목의 값이 **같아야** 같은 대상으로 봅니다. 이름이 같은 다른 건물을 구분할 때 "대상물명 + 주소"로 쓰면 좋습니다.
- 같은 대상은 목록을 건너서도 이어집니다. A 목록과 B 목록이 같고 B와 C가 같으면 A·B·C가 한 대상이 됩니다.
- **괄호만 덧붙은 이름**은 주소(도로·번호)까지 같으면 같은 대상으로 봅니다. 판정에 `괄호만 다름`이 붙습니다.
  예: `서울정심초등학교` = `서울정심초등학교(병설유 포함)`, `호압사` = `호압사(석불좌상)`
  괄호 없는 이름이 없고 괄호 내용만 서로 다르면(`가산디지털단지역(7호선)` / `(국철)`) 합치지 않고 비슷한 후보로 보여 줍니다.
- 주소의 띄어쓰기 차이(`시흥대로 47길 43` = `시흥대로47길 43`)는 같은 주소로 봅니다.
- 한 파일 안에 같은 대상이 두 번 이상 들어 있으면 **파일 안 중복**으로 따로 표시합니다.

| 옵션 | 하는 일 | 예 |
|---|---|---|
| 띄어쓰기 무시 (기본 켜짐) | 공백을 지우고 비교 | `시흥빌딩` = `시흥 빌딩` |
| 이름이 같아도 주소가 다르면 다른 대상 (기본 켜짐) | 주소의 도로와 번호가 다르면 따로 봄. 한쪽에 주소가 없으면 이름만으로 맞춤 | `어반팰리스(독산로 329)` ≠ `어반팰리스(두산로 5-8)` |
| 영문 대소문자 무시 (기본 켜짐) | 대소문자 구분 안 함 | `W센터` = `w센터` |
| 기호 무시 | `- . , ( )` 등을 지우고 비교 | `W-센터` = `W센터` |
| 오타 의심 후보 찾기 | 철자가 비슷한 쌍을 후보로 표시 (아래 4번) | `물류센터` ≈ `물류센타` |

### 3. 인근 대상물 (팀 배분용)
가까운 곳에 있는 대상을 인근 대상물로 함께 표시합니다. 같은 번호(`인근 01` 등)가 붙은 대상끼리 가까이 있습니다. 같은 팀이 한 번에 돌 수 있도록 배분할 때 참고합니다.

- 각 파일의 **주소 열**을 고릅니다. 보통 자동으로 잡힙니다.
- **인근 범위**를 고릅니다.

| 범위 | 대략적인 거리 |
|---|---|
| 같은 건물만 | 건물번호까지 같은 곳 |
| 번호 10 이내 | 약 100m |
| 번호 20 이내 (기본) | 약 200m |
| 번호 50 이내 | 약 500m |

> 도로명주소의 건물번호는 도로를 따라 약 10m마다 1씩 늘어납니다. 그래서 **같은 도로**에서 번호 차이로 거리를 어림합니다. 다른 도로에 있는 대상은 실제로 가까워도 인근 대상물로 보지 않습니다.
> 지번주소는 번호와 거리가 비례하지 않아 **같은 동·같은 본번**일 때만 인근 대상물로 봅니다.
> 주소를 읽지 못한 대상은 인근 대상물에서 빠지고, 화면에 그 건수가 표시됩니다.

### 4. 오타 의심 후보 확인
이름이 완전히 같지는 않지만 비슷한 쌍을 **비슷한 후보** 탭에 모아 보여 줍니다. 서로 다른 두 목록 사이의 모든 조합에서 찾습니다.

- 한글을 자음·모음 단위로 쪼개 비교합니다. `센터`와 `센타`는 모음 하나만 달라 높은 유사도로 나옵니다.
- 시트가 여러 개인 파일은 **같은 파일의 다른 시트끼리도** 찾습니다. 이미 상대 시트에 짝이 있는 행은 빼고 찾습니다.
- 주소까지 같으면 **같은 주소** 표시가 붙고 목록 위쪽에 나옵니다.
- 이름 속 숫자가 다르면(`101동`/`102동`, `제1공장`/`제2공장`) 다른 대상으로 보고 후보에 넣지 않습니다.
- 쌍마다 **같은 대상** 또는 **다른 대상**을 누릅니다.
  - 같은 대상 → 두 대상이 하나로 합쳐지고 판정이 "직접 확정"으로 기록됩니다.
  - 다른 대상 → 후보 목록에서 빠집니다.
- 잘못 확정한 것은 **대조표** 탭의 **취소**로 되돌립니다.
- 유사도 기준은 95% / 90% / 85%(기본) / 75% 중에서 고릅니다. 기준을 낮추면 후보가 늘어납니다.

> 오타는 자동으로 합치지 않습니다. 이름만 비슷한 다른 대상이 합쳐지는 것을 막기 위해 반드시 사람이 확정합니다.
> 어떤 파일의 시트·머리글 행을 바꾸거나 파일을 바꾸기·빼기 하면, 그 파일이 들어간 판정만 초기화됩니다.

### 5. 결과 확인과 내려받기
화면 위쪽에 **전체 대상물 / 2개 이상 목록에 있음 / 모든 목록에 있음 / 인근 대상물**, 그 아래에 파일마다 **○○에만 있음** 건수가 나옵니다.

| 탭 | 내용 |
|---|---|
| 대조표 | 대상물마다 각 목록에 있는지 `○`와 원본 행 번호, **해당 구분**(파일·시트)으로 표시. `2개 이상 구분`, `2개 이상 목록`, `모든 목록`, `○○에만`, `파일 안 중복`으로 걸러 보기 |
| 비슷한 후보 | 오타 의심 쌍과 판정 버튼 |
| 인근 대상물 | 인근 번호별 대상과 있는 목록 |
| 파일별 탭 | 그 파일의 원본 행에 다른 목록 위치와 인근 대상물을 붙여 보기 |

**통합 결과 파일 내려받기**를 누르면 엑셀 파일 하나에 아래 시트가 들어갑니다.

| 시트 | 내용 |
|---|---|
| 팀배분 요약 | 센터·팀별 대상 수, 목록별 건수, 함께 방문·단독 건수, 등급별 건수, 주요 동, 나누는 기준 |
| 요약 | 파일별 전체 행·다른 목록과 중복·이 목록에만·파일 안 중복 건수, 전체 대상물 수, 비교 항목·옵션, 작성 일시 |
| 대조표 | 전체 대상물. 목록 수, **해당 구분·구분 수**, 목록마다 `○`와 원본 행 번호, 시트가 여러 개인 파일은 **시트마다 `○` 칸**, 인근 대상물, 판정. 많은 목록·구분에 있는 대상부터 정렬 |
| 중복대상 | 2개 이상 목록에 있는 대상. 한 줄에 목록별 원본 정보를 나란히 표시. `판정` 열에 자동 일치 / 직접 확정 |
| ○○에만 | 파일마다 하나씩. 그 목록에만 있는 대상. 확인하지 않은 오타 후보는 `비슷한 후보(확인 필요)` 열에 표시 |
| 배분용 전체대상 | 중복을 하나로 합친 전체 대상. 관할센터·배정 팀·동·등급·업무량 포함, 센터 → 팀 → 동 순 정렬 |
| 배정 ○○팀 | 팀마다 하나씩. 그 팀이 맡을 대상과 할 일(있는 목록), 완료·비고 칸 |
| ○○ 전체 | 파일마다 하나씩. 원본 전체에 `중복여부`(몇 개 목록), `다른 목록 위치`, `인근 대상물` 열을 붙이고 중복 행은 노란색 |

파일이 N개면 시트는 `2N + 4`개입니다(3개 파일 → 10개 시트).

- 모든 시트의 `행` 번호는 **원본 엑셀의 행 번호**입니다. 원래 파일에서 바로 찾아갈 수 있습니다.
- 시트마다 자동 필터가 걸려 있습니다.
- 한 부서 원본에 표시만 해서 받고 싶으면 **○○ 표시본** 버튼을 씁니다.

### 6. 팀 배분
비교 결과를 관할센터별로 팀에 나눕니다. 예를 들어 화재안전조사 목록과 소방훈련 목록을 함께 올리면, 두 목록에 다 있는 대상은 한 팀이 한 번 방문해 조사와 훈련을 같이 하도록 배정합니다.

1. **관할 열·등급 열**: 파일마다 `관할센터`, `대상물구분` 열이 자동으로 골라집니다. `대응단`처럼 줄여 적은 센터 이름은 `현장대응단`으로 합쳐집니다.
2. **팀 이름**: 센터마다 쉼표로 입력합니다(기본 `1팀, 2팀, 3팀`). 팀 수를 바꾸면 바로 다시 나눕니다.
3. **나누는 기준**

| 기준 | 하는 일 | 좋은 점 / 아쉬운 점 |
|---|---|---|
| 목록별 건수를 똑같이 (기본) | 대상을 "조사만 / 훈련만 / 둘 다"로 나누고, 종류마다 지역 순서대로 팀 수만큼 똑같이 나눔 | 팀마다 조사·훈련·함께 방문 건수가 모두 같음 / 팀이 맡는 지역이 조금 겹칠 수 있음 |
| 대상 수만 똑같이 | 지역 순서대로 늘어놓고 대상 수로만 똑같이 나눔 | 지역이 가장 잘 모임 / 팀마다 조사·훈련 비율이 다를 수 있음 |
| 업무량 가중치로 | 등급·업무 종류 가중치를 곱한 업무량 합계로 나눔 | 큰 대상을 반영 / 건수는 팀마다 다름 |

**중요 대상도 팀마다 고르게 (옵션)** — 목록별 건수·대상 수 기준에서 씁니다.
- 체크하면 중요하게 볼 **등급**(특급·1급·2급·3급)과 **구분**(파일·시트, 예: `조사·중점관리대상`, `훈련·고층건축물`)을 여러 개 고를 수 있습니다.
- 팀마다 건수는 그대로 두고, 고른 항목마다 팀이 가진 수가 고르게 되도록 나눕니다. 한 대상이 여러 항목에 들면 모두 셉니다.
- 예 (현장대응단 3개 팀, 특급·1급·조사 중점관리대상·훈련 고층건축물): 특급 2/2/5 → 3/3/3, 1급 96/82/60 → 79/80/79, 조사 중점관리대상 15/6/7 → 9/10/9
- 대신 중요 대상이 지역 순서를 벗어나 배정되므로, 팀이 맡는 지역이 더 섞입니다. 팀배분 요약과 팀 시트에 `중요` 칸이 생깁니다.

예 (현장대응단, 3개 팀, 목록별 건수를 똑같이): 1팀 조사 204·훈련 130, 2팀 203·130, 3팀 202·128

**결과 "팀 배분" 탭**
- 센터·팀별 대상 수, 목록별 건수(조사·훈련 등), 함께 방문 건수, 목록별 단독 건수, 등급별 건수, 주요 동을 보여 줍니다. 업무량은 가중치 방식일 때만 나옵니다.
- 아래 목록에서 대상마다 **배정 팀**을 바꿀 수 있습니다. 바꾼 대상에는 `변경` 표시가 붙고, 설정 칸의 **되돌리기**로 한 번에 되돌립니다.

**엑셀**: 통합 결과 파일에 `팀배분 요약`, 팀마다 `배정 ○○팀`(완료·비고 칸 포함) 시트가 추가되고, `배분용 전체대상`에 배정 팀이 채워집니다.

### 7. 현장점검(field-check) 앱 업로드용 파일 만들기
현장점검(field-check) 맵 앱의 업로드용으로 이름·주소·팀·구분·관할센터·등급·용도·전화번호·비고 9개 열로 된 Excel 파일을 만듭니다. 접속 주소 <https://rcntiger.github.io/field-check/>

1. 크로스 체크에서 **파일의 팀열에 표시할 값**을 고르고 **현장점검(field-check)용 파일 내려받기**를 누릅니다.
   - `배정 팀`(기본): 팀 배분 결과(예: `현장대응단 1팀`)가 들어가 지도에서 팀별 색으로 보임
   - `미배정`: 엑셀을 열어 팀 칸을 직접 채운 뒤 올릴 때
   - `인근 대상물 번호`: 인근 번호별 색으로 먼저 지도에서 보고 싶을 때 (가까운 대상이 없으면 `단독`)
2. 현장점검 지도에서 계획을 만들거나 열고 **엑셀 업로드**로 이 파일을 올립니다.
3. 파일의 1행은 제목, 2행은 머리글(`이름 / 주소 / 팀 / 구분 / 관할센터 / 등급 / 용도 / 전화번호 / 비고`)입니다. 현장점검 지도(v3.2.0 이상)가 제목 줄을 건너뛰고 열을 자동으로 잡습니다. 확인만 누르면 주소가 좌표로 바뀌어 마커가 찍힙니다.

| 지도용 파일 열 | 지도에서 쓰이는 곳 |
|---|---|
| 이름 | 마커 이름표, 목록 |
| 주소 | 좌표 변환, 길찾기 |
| 팀 | 마커 색, 그룹 필터 |
| 구분 | 대상이 든 목록 이름(예: `조사`, `훈련`, `조사·훈련`). 마커 모양(여러 목록 대상은 두 겹 테두리), 업무 구분 필터, 툴팁·정보카드 표시 |
| 관할센터 · 등급 · 용도 | 원본 목록의 관할센터, 관리등급(여러 목록이면 높은 등급), 용도. 정보카드에 한 줄씩 나옴 (지도 v3.7.0 이상에서 미리 골라짐). 원본에 없으면 `-` |
| 전화번호 | 원본에서 이름에 '전화'·'연락처'가 들어간 열(팩스 제외). 지도 정보카드에서 누르면 전화 걸기 (지도 v3.8.0 이상). 없으면 `-` |
| 비고 | 정보카드의 추가정보 (있는 목록, 인근 번호, 목록별 원본 행 번호) |

> 현장점검 지도는 엑셀의 **빈 칸을 바로 위 칸 값으로 채웁니다**(병합 셀 처리). 팀 칸을 직접 채울 때 일부를 비워 두면 위 행의 팀이 그대로 들어가니, 모든 행을 채우거나 `미배정`을 남겨 두세요.

## 알아 두실 점

- 결과 파일에서 원본의 글꼴·테두리·색 같은 셀 서식은 단순해질 수 있습니다. **원본 파일은 따로 보관**하세요.
- 병합된 셀이 많은 표는 머리글이 제대로 읽히지 않을 수 있습니다. 이때는 병합을 풀거나 머리글 행 번호를 조정하세요.
- 화면 미리보기는 탭마다 앞의 500행까지만 보여 줍니다. 내려받는 파일에는 전체가 들어갑니다.
- 처음 열면 빈 화면입니다. 결과 화면을 미리 보고 싶으면 **예시로 둘러보기**를 누르세요. 예시 파일 카드에는 `예시` 표시가 붙고, 실제 파일을 올리거나 **예시 지우기**를 누르면 빠집니다.
- 파일 5개 × 약 1,800행(총 9,000행)을 비교하는 데 오타 후보 찾기까지 1~2초 걸립니다.
