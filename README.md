# 대상물 크로스 체크

부서마다 따로 내려온 엑셀 대상물 목록 두 개를 맞대어 **겹치는 대상(중복)**, **한쪽에만 있는 대상**, **가까운 주소에 모인 대상**을 찾아 주는 웹 도구입니다. 점검·교육 대상을 팀별로 배분하기 전에 목록을 정리하는 용도로 만들었습니다.

- 설치 없이 브라우저(크롬, 엣지)에서 바로 실행됩니다.
- 올린 파일은 **브라우저 안에서만 처리**되며 서버나 외부로 전송되지 않습니다.
- 인터넷이 없는 PC에서도 동작합니다. 엑셀 처리 라이브러리를 파일 안에 넣어 두었습니다.

---

## 사용 방법

### 1. 파일 올리기
파일 A와 파일 B 칸에 엑셀 파일을 끌어다 놓거나, 칸을 눌러 파일을 고릅니다.

- 지원 형식: `.xlsx`, `.xls`, `.xlsm`, `.csv` (CSV는 UTF-8과 EUC-KR 모두 읽음)
- **부서/구분 이름**: "예방과", "대응단"처럼 적어 두면 결과 화면과 엑셀 시트 이름에 그대로 쓰입니다.
- **시트**: 파일에 시트가 여러 개면 비교할 시트를 고릅니다.
- **머리글 행**: 자동으로 찾습니다. 위에 문서 제목, 작성일, 단위, 빈 줄이 있어도 건너뛰고 표의 머리글 줄을 고릅니다. 자동으로 고른 행에는 `자동` 표시가 붙습니다.
  - 잘못 잡혔으면 숫자를 직접 고칩니다. 다시 자동으로 돌리려면 `자동으로`를 누릅니다.
- **병합 셀**: 그대로 올려도 됩니다.
  - 세로로 병합된 칸(예: 한 건물에 업소가 여러 개라 `건물명`·`주소`가 병합된 경우)은 병합된 모든 행에 같은 값이 들어간 것으로 읽습니다.
  - 머리글이 병합으로 두 줄이면(예: `소재지` 아래 `도로명 / 지번`) `소재지 도로명`, `소재지 지번`처럼 한 이름으로 합칩니다.
  - 병합 없이 빈칸만 둔 두 줄 머리글은 위 줄만 머리글로 잡고 아래 줄을 데이터로 읽습니다. 이때는 엑셀에서 머리글을 한 줄로 합쳐 두세요.

### 2. 비교 기준 정하기
두 파일에서 같은 대상인지 판단할 열을 고릅니다. 열 이름이 서로 달라도 됩니다(예: `대상물명` ↔ `명칭`).

- "대상물명", "명칭", "주소", "소재지" 같은 열은 자동으로 짝지어 줍니다.
- **기준 열 추가**를 누르면 여러 열을 함께 비교합니다. 이때는 고른 열의 값이 **모두 같아야** 중복으로 봅니다. 이름이 같은 다른 건물을 구분할 때 "대상물명 + 주소"로 쓰면 좋습니다.

| 옵션 | 하는 일 | 예 |
|---|---|---|
| 띄어쓰기 무시 (기본 켜짐) | 공백을 지우고 비교 | `시흥빌딩` = `시흥 빌딩` |
| 영문 대소문자 무시 (기본 켜짐) | 대소문자 구분 안 함 | `W센터` = `w센터` |
| 기호 무시 | `- . , ( )` 등을 지우고 비교 | `W-센터` = `W센터` |
| 오타 의심 후보 찾기 | 철자가 비슷한 쌍을 후보로 표시 (아래 4번) | `물류센터` ≈ `물류센타` |

### 3. 인근 주소 묶음 (팀 배분용)
가까운 곳에 있는 대상을 한 묶음으로 표시합니다. 같은 팀이 한 번에 돌 수 있도록 배분할 때 참고합니다.

- 각 파일의 **주소 열**을 고릅니다. 보통 자동으로 잡힙니다.
- **묶음 범위**를 고릅니다.

| 범위 | 대략적인 거리 |
|---|---|
| 같은 건물만 | 건물번호까지 같은 곳 |
| 번호 10 이내 | 약 100m |
| 번호 20 이내 (기본) | 약 200m |
| 번호 50 이내 | 약 500m |

> 도로명주소의 건물번호는 도로를 따라 약 10m마다 1씩 늘어납니다. 그래서 **같은 도로**에서 번호 차이로 거리를 어림합니다. 다른 도로에 있는 대상은 실제로 가까워도 묶이지 않습니다.
> 지번주소는 번호와 거리가 비례하지 않아 **같은 동·같은 본번**일 때만 묶습니다.
> 주소를 읽지 못한 대상은 묶음에서 빠지고, 화면에 그 건수가 표시됩니다.

### 4. 오타 의심 후보 확인
이름이 완전히 같지는 않지만 비슷한 쌍을 **비슷한 후보** 탭에 모아 보여 줍니다.

- 한글을 자음·모음 단위로 쪼개 비교합니다. `센터`와 `센타`는 모음 하나만 달라 높은 유사도로 나옵니다.
- 주소까지 같으면 **같은 주소** 표시가 붙고 목록 위쪽에 나옵니다.
- 쌍마다 **같은 대상** 또는 **다른 대상**을 누릅니다.
  - 같은 대상 → 중복대상으로 옮겨지고 판정이 "직접 확정"으로 기록됩니다.
  - 다른 대상 → 후보 목록에서 빠집니다.
- 잘못 확정한 것은 **중복대상** 탭의 **취소**로 되돌립니다.
- 유사도 기준은 95% / 90% / 85%(기본) / 75% 중에서 고릅니다. 기준을 낮추면 후보가 늘어납니다.

> 오타는 자동으로 합치지 않습니다. 이름만 비슷한 다른 대상이 합쳐지는 것을 막기 위해 반드시 사람이 확정합니다.
> 파일, 시트, 머리글 행을 바꾸면 확정한 판정이 초기화됩니다.

### 5. 결과 확인과 내려받기
화면 위쪽에 **중복 / ○○에만 / ○○에만 / 인근 묶음** 건수가 나오고, 아래 탭에서 자세한 내용을 봅니다.

**통합 결과 파일 내려받기**를 누르면 엑셀 파일 하나에 아래 시트가 들어갑니다.

| 시트 | 내용 |
|---|---|
| 요약 | 부서별 전체·중복·단독 건수, 직접 확정 건수, 남은 오타 후보, 비교 기준·옵션, 작성 일시 |
| 중복대상 | 양쪽 모두에 있는 대상. 한 줄에 두 부서 정보를 나란히 표시. `판정` 열에 자동 일치 / 직접 확정 구분 |
| ○○에만 | A 부서 파일에만 있는 대상. 확인하지 않은 오타 후보가 있으면 `비슷한 후보(확인 필요)` 열에 표시 |
| ○○에만 | B 부서 파일에만 있는 대상 |
| 배분용 전체대상 | 중복을 하나로 합친 전체 대상 목록. 인근 묶음끼리 붙여 정렬하고 빈 `배정 팀` 열 포함 |
| ○○ 전체 | A 부서 원본 전체. 중복 행은 노란색, 상대 부서 행 번호와 인근묶음 표시 |
| ○○ 전체 | B 부서 원본 전체. 같은 방식으로 표시 |

- 모든 시트의 `행` 번호는 **원본 엑셀의 행 번호**입니다. 원래 파일에서 바로 찾아갈 수 있습니다.
- 시트마다 자동 필터가 걸려 있습니다.
- 한 부서 원본에 표시만 해서 받고 싶으면 **○○ 표시본만** 버튼을 씁니다.

### 6. 현장점검 지도로 보내기
정리한 대상을 [현장 확인 점검 Map](https://rcntiger.github.io/field-check/)에 올려 지도에 표시할 수 있습니다.

1. 크로스 체크에서 **팀 칸에 넣을 값**을 고르고 **현장점검 지도용 파일 내려받기**를 누릅니다.
   - `미배정`: 엑셀을 열어 팀 칸을 직접 채운 뒤 올릴 때
   - `인근 묶음 번호`: 묶음별 색으로 먼저 지도에서 보고 싶을 때 (묶이지 않은 대상은 `단독`)
2. 현장점검 지도에서 계획을 만들거나 열고 **엑셀 업로드**로 이 파일을 올립니다.
3. 파일의 1행은 제목, 2행은 머리글(`이름 / 주소 / 팀 / 비고`)입니다. 현장점검 지도의 기본 설정(헤더 행 2행)과 맞아서 열이 자동으로 잡힙니다. 확인만 누르면 주소가 좌표로 바뀌어 마커가 찍힙니다.

| 지도용 파일 열 | 지도에서 쓰이는 곳 |
|---|---|
| 이름 | 마커 이름표, 목록 |
| 주소 | 좌표 변환, 길찾기 |
| 팀 | 마커 색, 그룹 필터 |
| 비고 | 정보카드의 추가정보 (출처, 묶음, 원본 행 번호) |

> 현장점검 지도는 엑셀의 **빈 칸을 바로 위 칸 값으로 채웁니다**(병합 셀 처리). 팀 칸을 직접 채울 때 일부를 비워 두면 위 행의 팀이 그대로 들어가니, 모든 행을 채우거나 `미배정`을 남겨 두세요.

## 알아 두실 점

- 결과 파일에서 원본의 글꼴·테두리·색 같은 셀 서식은 단순해질 수 있습니다. **원본 파일은 따로 보관**하세요.
- 병합된 셀이 많은 표는 머리글이 제대로 읽히지 않을 수 있습니다. 이때는 병합을 풀거나 머리글 행 번호를 조정하세요.
- 화면 미리보기는 탭마다 앞의 500행까지만 보여 줍니다. 내려받는 파일에는 전체가 들어갑니다.
- 처음 열면 예시 데이터가 들어 있습니다. 파일을 올리면 그 데이터로 바뀝니다.

## 파일 구성

```
crosscheck/
├── index.html     프로그램 본체 (이 파일 하나로 실행)
├── README.md      설명서
└── CHANGELOG.md   변경 이력
```

바뀐 내용은 [CHANGELOG.md](CHANGELOG.md)에서 볼 수 있습니다.
